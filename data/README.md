# Data

- `raw/` holds the committed reproducible sample of 12 rows, copied verbatim from the full file with all 67 columns. It covers India, the United States, Brazil, South Africa and the OWID World aggregate on 2021-12-31 and 2023-12-31, plus the split-duplicate pair for the Faroe Islands on 2021-01-29, which exercises the merge step in `sql/02`. It is generated by `scripts/make_sample.py` and runs end to end with `python run_pipeline.py --source sample`.
- `raw_full/` is git-ignored. Fill it with `python scripts/download_full_data.py`, which also verifies SHA-256.
- `clean_full/` is git-ignored. `run_pipeline.py --source full` writes the cleaned star tables there.
